Click a lesson to open it. Each lesson is one self-contained file; nothing to install and no server. Press Play: Space pauses, →/← step, 1–4 answer, T enlarges the figure, and L opens the map. Opened from disk, a lesson has no Tutor, which needs a model API; the video shows it.

If your browser blocks a link (for example, a file-access message on macOS), open the lesson file directly from this lessons folder: each file below works on its own.
